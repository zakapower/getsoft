# Getsoft

Каталог официальных загрузок для Windows. Кнопка «Скачать» ведёт на сайт издателя — файлы мы не хостим.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Добавить приложение

Правьте `src/data/apps.ts`: slug, `officialUrl`, категория, `featured`.

## Стек

Next.js (App Router), TypeScript, plain CSS, i18n RU/EN.
